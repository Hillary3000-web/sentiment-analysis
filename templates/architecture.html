System Architecture

How SentimentIQ processes human language and assigns emotional polarity using classical Machine Learning.

Data Pipeline

Before any model can understand text, the raw input must be mathematically encoded. SentimentIQ uses an NLP pipeline to process the data:

Text Processing Pipeline

1. Tokenization: Splitting sentences into individual words.

2. Stopword Removal: Filtering out common English words (like "the", "is", "and") that carry no emotional weight.

3. TF-IDF Vectorization: Converting words into numerical matrices using Term Frequency-Inverse Document Frequency. This emphasizes words that are highly specific to a sentiment while down-weighting generic terms.

The Models

Naïve Bayes Classifier

Naïve Bayes is a probabilistic model based on Bayes' Theorem. It calculates the probability of a sentiment label given the specific words in the text.

P(Label | Words) = P(Words | Label) * P(Label) / P(Words)

Despite the "naïve" assumption that every word is independent of the others, it performs exceptionally well on text classification tasks and requires very little training data to be highly accurate.

Logistic Regression

Instead of calculating probabilities of individual features like Naïve Bayes, Logistic Regression learns the optimal weights for each word to predict the outcome.

f(x) = 1 / (1 + e^-(β0 + β1x1 + ... + βnxn))

It passes a linear combination of the TF-IDF vectors through a Sigmoid function, mapping any value to a smooth probability curve between 0 (Negative) and 1 (Positive).
